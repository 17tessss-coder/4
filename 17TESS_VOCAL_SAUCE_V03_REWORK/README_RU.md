# 17TESS VOCAL SAUCE — V0.3 REWORK

Это обновлённая версия исходников под твои правки.

## Что изменено

- UI переработан ближе к новому пиксельному референсу.
- Добавлен новый блок **COMPRESSOR**.
- Основные эффекты стали заметно чувствительнее:
  - почти все основные ручки усилены примерно **в 3 раза**;
  - **DISTORTION** усилен примерно **в 2 раза**, но с более точной тонкой настройкой.
- Добавлены тонкие настройки для эффектов через кнопки **+**.
- EQ расширен:
  - теперь **6 точек** вместо 3;
  - диапазон по усилению **от -36 dB до +36 dB**;
  - точки можно двигать свободно по всей области графика.
- Сохранение и загрузка пользовательских пресетов сохранены.

## Что лежит в проекте

- `source/` — исходники JUCE-плагина
- `.github/workflows/build-win64.yml` — GitHub Actions для сборки `.vst3`
- `CMakeLists.txt` — CMake-конфиг

## Как собрать .vst3 через GitHub

### Вариант 1 — если создаёшь новый репозиторий

1. Создай пустой репозиторий на GitHub.
2. Загрузи **всё содержимое** этой папки в корень репозитория.
3. Убедись, что в репозитории есть:
   - `CMakeLists.txt`
   - папка `source`
   - папка `.github/workflows`
   - файл `.github/workflows/build-win64.yml`
4. Открой вкладку **Actions**.
5. Слева выбери workflow **Build 17TESS Vocal Sauce Win64 VST3**.
6. Нажми **Run workflow**.
7. Дождись зелёного статуса **Success**.
8. Открой вкладку **Summary** у успешной сборки.
9. Внизу в блоке **Artifacts** скачай архив `17TESS-Vocal-Sauce-Win64-VST3`.

### Вариант 2 — если обновляешь уже существующий репозиторий

1. Удали или замени старые файлы проекта новыми.
2. Особенно важно заменить:
   - `source/PluginProcessor.cpp`
   - `source/PluginProcessor.h`
   - `source/PluginEditor.cpp`
   - `source/PluginEditor.h`
   - `source/DSPCore.h`
   - `CMakeLists.txt`
3. Закоммить изменения.
4. Перейди в **Actions** и дождись новой сборки.
5. Скачай артефакт.

## Установка VST3 в Windows

1. Распакуй архив артефакта.
2. Внутри будет папка `17TESS VOCAL SAUCE.vst3`.
3. Скопируй эту папку целиком сюда:

`C:\Program Files\Common Files\VST3\`

4. Перезапусти Cubase.
